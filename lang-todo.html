1تعريف المحاسبة وال Introduction

المادة دي نفس مادة المحاسبة بس بالإنجليزي، فهمك للمحاسبة يساعدك.

  • Accounting = المحاسبة: نظام لتسجيل وتلخيص العمليات المالية وتوصيلها للمهتمين.
  • Introduction = مقدمة.
  • Transaction = عملية مالية.
  • Business = المشروع. Owner = صاحب المشروع.

نصيحة: احفظ الكلمة وترجمتها معًا، والامتحان بيجي منهم.

  • Managerial accounting = المحاسبة الإدارية
  • Cost accounting = محاسبة التكاليف
  • Governmental accounting = المحاسبة الحكومية

3Internal user و External user
  • Internal user = مستخدم داخلي: من جوا المشروع. مثلًا Managers (المديرين).
  • External user = مستخدم خارجي: من بره المشروع. زي Investors (المستثمرين)، Creditors (الدائنين)، Government (الحكومة)، Customers (العملاء).

طريقة تفتكر: Internal = جوا (in)، External = بره (ex).

Accounting – Introduction (ركز عليها)

  • Definition: Accounting is an information system that identifies, records, classifies, summarizes and communicates financial information about an economic entity to users who make decisions.
    (المحاسبة نظام معلومات يحدد ويسجل ويبوّب ويلخص ويوصل المعلومات المالية عن منشأة لمتخذي القرارات.)

  • The accounting process: Recording → Classifying → Reporting (Summarizing) → Interpreting.

  • Branches of accounting (فروع المحاسبة): Financial accounting (external users) | Managerial accounting (internal users) | Cost accounting (cost of production) | Government accounting | Tax accounting | Auditing (المراجعة).
  • Internal users (مستخدمون داخليون): managers, owners-managers, employees → need information for planning and control.
  • External users (مستخدمون خارجيون): investors/shareholders, creditors (banks, suppliers), government and tax authorities, customers.
  • The accounting equation: Assets = Liabilities + Owners' Equity (الأصول = الالتزامات + حقوق الملكية).
    Assets: what the business owns. Liabilities: what it owes to outsiders. Owner's equity: the owner's claim.

Math in English: Linear equations, absolute value, slope & line

  • Linear equation: ax + b = c → solve: move terms, then divide. Example: 3x − 3 = 7 → 3x = 10 → x = 10/3.
  • Absolute value: |x| = a (a ≥ 0) → x = a or x = −a. |A| = |B| → A = B or A = −B. (حلولها في قسم الرياضة فوق.)
  • Slope (الميل): m = (y₂ − y₁) ÷ (x₂ − x₁).
  • Equation of a straight line (معادلة الخط المستقيم): y = mx + c ، c = y-intercept (المقطع الصادي). From a point: y − y₁ = m(x − x₁).
    • مثال: الخط يمر بالنقطتين (2,3) و(4,7): m = (7−3)/(4−2) = 2 → y − 3 = 2(x − 2) → y = 2x − 1.
  • Parallel lines: equal slopes. Perpendicular: m₁·m₂ = −1.
  • ولما الـ x يكون أسها غير 1 (non-linear): المعادلة التربيعية ax² + bx + c = 0 تحل بالتحليل أو بالقانون x = (−b ± √(b² − 4ac)) ÷ 2a. مثال: x² − 5x + 6 = 0 → (x−2)(x−3) = 0 → x = 2 أو x = 3.
1المعادلة المحاسبية بالإنجليزي

نفس معادلة المحاسبة، بس بالإنجليزي:

Assets = Liabilities + Owner’s Equity
  • Assets = الأصول (اللي المشروع يملكه).
  • Liabilities = الالتزامات (الديون على المشروع).
  • Owner’s Equity = حقوق الملكية (نصيب صاحب المشروع).

الأدمن نزل فيديوهات شرح للنقطة دي في الجروب (متجمعة في تبويب فيديوهات).

③ المعادلة المحاسبية (المحور الأساسي)

Assets = Liabilities + Owner's Equity (الأصول = الخصوم + حقوق الملكية)

  • الأصول (ما تملكه المنشأة) | الخصوم (التزامات للغير) | حقوق الملكية (ملك صاحب المشروع = رأس المال + الإيرادات − المصروفات − المسحوبات).
  • لازم دايمًا متوازنة (المعاملة الواحدة تؤثر على جانبين على الأقل، ومجموع الطرفين يفضل متساوي).
  • Owner's equity يزيد بـ: الاستثمار (Capital) والإيرادات Revenue. ينقص بـ: المصروفات Expenses والمسحوبات Withdrawals/Drawings.
  • Net income = Revenue − Expenses (لو موجب ربح، لو سالب Net loss).
  • قائمة الدخل تاريخها "For the year ended Dec 31" (فترة) والميزانية "On Dec 31" (لحظة).
1المعادلة الخطية والميل

الفكرة: تخيل طريق طالع. الميل هو مدى انحداره: كل ما مشيت متر لقدام، بتعلى كام متر؟ ومعادلة الخط المستقيم بتوصف الطريق ده:

y = m·x + b
  • m = الميل (الخط بيطلع قد إيه كل ما x تزيد ①.
  • b = المكان اللي الخط بيقطع فيه محور y.

إزاي تجيب الميل من نقطتين:

m = (y2 − y1) / (x2 − x1)

مثال: النقطتين (1, 2) و(3, 6):

m = (6 − 2) / (3 − 1) = 4/2 = 2

وبعدين عوض بنقطة في y = 2x + b: 2 = 2×1 + b فـ b = 0، والمعادلة y = 2x.

2القيمة المطلقة

القيمة المطلقة = بعد الرقم عن الصفر على خط الأرقام، والبعد مش ممكن يبقى سالب. يعني |5| = 5، و|−5| = 5 كمان (الاتنين بعدهم 5 خطوات عن الصفر).

الحل:

|x| = 3 ⟹ x = 3 أو x = −3
|x| < 3 ⟹ −3 < x < 3
|x| > 3 ⟹ x > 3 أو x < −3

لما x أسّها مش واحد: x² = 9 يعني x = 3 أو x = −3 (جذر الطرفين، ولازم تاخد الحالتين).

▶ أسهل طريقة لحل معادلات القيمة المطلقة ⏱ 9 د

Linear Equation (الفصل 2 – ص215–252.
  • الصورة العامة: y = mx + c حيث m = Slope (الميل) و c = Intercept (المقطع).
  • شكل عام: ax + by = c. مثال: 2x + 4y = 16 والنقطة (2,3): 2(2) + 4(3) = 4 + 12 = 16 ✓ (فالنقطة تقع على الخط).
  • تحقق دايمًا بالتعويض.
  • (باقي الفصل: رسم الخط، تقاطع خطين، حل نظام معادلتين، ما فهمتش منه شيء لأني قريت أول ورقتين بس من شرح 5/10.)
قواعد حل المعادلات
  • معادلة خطية: اجمع/اطرح من الطرفين ثم اقسم. مثال: 2x − 1 = 4 → 2x = 5 → x = 5/2.
  • معادلة القيمة المطلقة |A| = k: A = k أو A = −k. مثال: |x − 4| = 3 → x − 4 = 3 أو x − 4 = −3 → x = 7 أو x = 1.
  • |A| = |B|: A = B أو A = −B (وفحص الجواب بالتعويض).
    • |10 − 2x| = |2x + 5|: (أ) 10 − 2x = 2x + 5 → x = 5/4 = 1.25 | (ب) 10 − 2x = −2x − 5 → 10 = −5 مستحيل، يُهمل. الحل: x = 5/4.
    • |x − 4| = |2x − 3|: x − 4 = 2x − 3 → x = −1 | x − 4 = −2x + 3 → x = 7/3. x = −1 أو 7/3 (حلّيتها أنا، مش من الشيت).
    • |4x − 3| = 12: 4x − 3 = 12 → x = 15/4 | 4x − 3 = −12 → x = −9/4.
  • المتباينات (Inequalities): نفس خطوات المعادلة، لكن لو ضربت أو قسمت في سالب اقلب الإشارة.
    • 4x + 4 ≤ 12 → x ≤ 2 (من شيت الطالبة). 3x − 3 ≤ 7 → x ≤ 10/3.
    • المتباينة المزدوجة: x + 1 ≤ x ≤ 4 − x: الجزء الأول يعطي 1 ≤ 0 وده مستحيل ← لا يوجد حل (no solution) (مكتوب في شيت الطالبة "ليس لها حل").
    • 3x − 1 ≤ x ≤ 4x + 2 (سبورة د/هيثم): 3x − 1 ≤ x → x ≤ 1/2 | x ≤ 4x + 2 → x ≥ −2/3. الحل: −2/3 ≤ x ≤ 1/2 (حلّيتها أنا).
